# 劉家瑄 & 徐文倩｜婚禮邀請

以 HTML、Tailwind CSS CDN 與原生 JavaScript 製作的響應式單頁電子喜帖。

## 預覽

在瀏覽器中開啟 `index.html` 即可查看。也可以在專案資料夾啟動本機伺服器：

```bash
python3 -m http.server 8000
```

接著前往 <http://localhost:8000>。

頁面照片使用 `images/1.jpg` 至 `images/6.jpg`，交通資訊圖片使用 `images/transport/transport.jpg`。Tailwind CSS 與字型由 CDN 載入，使用時需連上網際網路。
